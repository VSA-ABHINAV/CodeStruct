## 2. Issue-by-Issue Resolution

### CS-001: Editor Navigation Session Binding & Path Traversal Prevention
- **Root Cause:** Navigation commands previously used an unbounded in-memory dictionary without strong session expiration, allowed path traversal if strings contained `..` or UNC prefixes, and did not confine navigation to the selected file capability.
- **Resolution:**
  - Implemented `EditorNavigationCommand` with TTL (default 120s) and bounded queue (last-wins).
  - Enforced strict canonical containment checks using `os.path.normcase` and symlink resolution.
  - Rejected any path containing `\x00`, drive letters (`C:`), UNC prefixes (`\\`), or `..` segments.
  - Enforced that a capability registered for a specific file only permits navigation targeting that identical file.
- **Evidence:** 20 test cases in `tests/test_navigate_routes.py` pass; verified via live API smoke test.

### CS-002: Thonny Destination Disambiguation & Cursor Index Alignment
- **Root Cause:** Thonny plugin searched all configured roots when opening files (leading to ambiguity when two projects contain `main.py`), passed 1-indexed column numbers directly to Tkinter text widgets (which expect 0-indexed character offsets), and retried indefinitely on authorization failures.
- **Resolution:**
  - Bound plugin worker state to `_nav_session_token` and `_nav_registered_file`.
  - Replaced root search with direct resolution against `_nav_registered_file`.
  - Converted column numbers: `col_offset = max(0, column - 1)`.
  - Handled 401/403/404/410 HTTP errors by posting a failed acknowledgment and stopping polling.
- **Evidence:** 44 tests in `thonny-plugin/tests` pass; verified in two-root disambiguation live smoke test.

### CS-003: Mypy Configuration Reconciliation & Linter Alignment
- **Root Cause:** Bare `python -m mypy` invocation failed because root `mypy.ini` lacked the module overrides and strict flags defined in `pyproject.toml`.
- **Resolution:** Reconciled `mypy.ini` with `pyproject.toml` so standard developer invocations pass cleanly without extra flags. Configured ruff per-file ignores for route dependencies and test session tokens.
- **Evidence:** `python -m mypy` passes across 50 files; `python -m ruff check` passes with 0 errors.

### CS-004 & CS-026: Frontend Contract Definition & Lovable Architecture Brief
- **Root Cause:** Frontend redesign requires stable, validated contract schemas and a clear design brief respecting the evidence principle and local proxy boundary.
- **Resolution:** Created `docs/frontend-contract/` containing all 6 canonical JSON payloads matching backend Pydantic models. Created `LOVABLE_FRONTEND_BRIEF.md` detailing screens, states, evidence rules, and graph engine evaluation.

### CS-023: Verification & Process Tracking
- **Resolution:** Documented real workflow evidence, automated suite results, and updated `PROCESS_TRACKER.md`.
