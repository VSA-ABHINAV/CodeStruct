# API v1 reference

`GET /health/live` reports process liveness and application version;
`GET /health/ready` additionally validates storage access and executor availability.
`GET /api/v1/version` returns the v1 identifier and package version. These
responses expose no configured paths, database locations, process IDs, or secrets.

Responses are JSON. Errors use `{api_version, request_id, error}` and never expose
canonical roots, source bodies, SQL, secrets, tracebacks, or worker IDs.

`GET /api/v1/projects` returns safe `id`, `display_name`, optional `description`,
and `available`. Paths are not returned. IDs are server-configured capabilities.

`POST /api/v1/analyses` accepts
`{"project":{"root_id":"alias","relative_path":"."},"options":{"metrics":false},"refresh":false}`.
`options.metrics: bool` (default `false`) controls graph metric calculation (fan-in/fan-out,
coupling, instability, centrality, cycle detection, and greedy modularity communities). When `true`,
the graph serializer marks `metadata.metrics_computed = true` and attaches metric attributes to nodes.
Analyses with `metrics: false` and `metrics: true` have distinct isolated cache keys. Cache hits
return 200 with `cache_hit: true` and preserve the original computed metrics.
`root_id` is preferred. `relative_path` remains temporarily compatible for
approved subpaths and is never an authorization proof. Success is 202 or 200 for
a cache hit. Unknown/unsafe roots are 403, missing directories 404, invalid bodies
422, unsupported options (custom grammar, inclusion/exclusion patterns) 400, and saturation 429.

`POST /api/v1/editor/selection` accepts `{"file_path":"/path/to/script.py"}`.
This loopback-only endpoint (`127.0.0.1`, `localhost`, `::1`) is designed for
editor integrations (such as the Thonny plugin). It validates that the path exists,
is a regular Python file (`.py` or `.pyw`), is not a symlink, and generates a
short-lived, single-file capability token `root_id` (`editor_<sha256>`) and
`relative_path` (`filename`). Analysis performed with this capability is strictly
scoped to the target file; sibling files and parent directories are never scanned,
authorized, or executed. Requests from non-loopback clients return 403. Missing or
non-Python files return 400.

`GET /api/v1/analyses/{analysis_id}` polls monotonic state. `DELETE` requests
cancellation and can race with completion. Useful terminal results are completed
or partially_completed.

Start graphs with `GET /api/v1/analyses/{analysis_id}/graph?limit=1000`. The
server caps pages; excess is `PAGE_LIMIT_EXCEEDED`. `page` provides returned/total
counts, `partial_load`, and an opaque `next_cursor`. Repeat the same limit with
the cursor. Cursors bind graph/filter and invalid/cross-result values return
`CURSOR_INVALID`. Context nodes accompany edge endpoints. Unbounded requests over
`CODESTRUCT_MAX_FULL_GRAPH_BYTES` return `GRAPH_TOO_LARGE`. Exact filters support
`node_kind`, `edge_kind`, and `resolution_status`.

`GET /api/v1/analyses/{analysis_id}/diagnostics` returns safe diagnostics.
Not-ready/unavailable is 409, expired 410, absent 404, and storage failure 503.
Graph responses are private/no-store. v1 evolution is additive; breaking changes
require a new major.
