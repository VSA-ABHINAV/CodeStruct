# Release limitations

- Public distribution is blocked: no owner-approved software license, maintainer identity, or project URLs exist.
- The local MVP has no authentication or TLS and is unsafe for unrestricted public exposure.
- Only Windows execution is currently verified; macOS, Linux, and the container remain pending.
- Real screen-reader, forced-colors, and 125%/200% zoom evidence is incomplete.
- Exhaustive disk-full, read-only database, worker-crash, and network fault injection remains incomplete.
- Dynamic analysis, incremental file caching, graph metrics, source navigation, LLM/RAG, and editor integration are not implemented.
- Dense/very large graphs use bounded retrieval and warnings but do not yet have virtualization or advanced aggregation.

See [known testing issues](../testing/known-issues.md) and the [release checklist](checklist.md).
