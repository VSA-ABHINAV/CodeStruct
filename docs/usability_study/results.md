## 4. Methodology & Limitations

- This is a **small-N convenience sample**; results are not statistically generalizable.
- This is a **self-contained before/after comparison within CodeStruct** comparing the
  baseline experience (Graph / Table / Inspector only) against the Advanced Architecture
  feature (Phase 19 component clustering + narrative).
- This study is **not a replication of, nor does it claim to outperform,** DSAR's own
  industrial evaluation (Rukmono et al., FSE Companion '26). DSAR's evaluation is a
  qualitative industrial judgment study with no single published number to numerically beat.
- Participants explored the same project under both conditions in **counterbalanced order**
  (half baseline first, half Advanced Architecture first) to control for learning-effect confound.
- Each participant completed the standard 10-item SUS instrument, a 3-item rubric (content
  quality, presentation quality, usefulness, 1-5 each), and one comprehension question once per condition.
- SUS scores use the standard validated formula (odd items: score-1; even items: 5-score; sum x 2.5).
- The result is reported as-is, whatever it is — if the measured improvement is below 1%, or
  even negative, that is what gets reported.
